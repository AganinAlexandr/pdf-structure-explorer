# pdf-structure-explorer

Web-приложение для загрузки, постраничного разбора, визуализации и инспекции структурных элементов PDF-файлов.

## Структура
- `backend/` - серверная часть и PDF-разбор
- `frontend/` - клиентский интерфейс
- `docs/` - проектная документация и ТЗ

## Инфраструктура
- код проекта: `E:/repos/pdf-structure-explorer`
- общие данные: `E:/commons`
- артефакты и экспорт: `E:/output/pdf-structure-explorer`

## Переменные окружения
См. `.env.example`.
