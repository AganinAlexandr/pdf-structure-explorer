# Excel Quick Start For `pdf-structure-explorer`

## Что это

Это практическая инструкция для быстрого подключения минимального набора Power Query-запросов в Excel без лишних технических таблиц на листах.

Основная идея:

- служебные запросы оставить как `Только подключение`
- полезные сводные таблицы загружать на отдельные листы

## Перед началом

Проверьте два пути:

- в `CurrentBundlePath.pq` должен быть путь к одному экспортированному пакету, например `E:\output\pdf-structure-explorer\exports\doc_dceda46d`
- в `ExportRootPath.pq` должен быть путь к корню экспорта: `E:\output\pdf-structure-explorer\exports`

## Рекомендуемый сценарий для одного PDF

### Оставить как `Только подключение`

Создайте в Excel эти запросы, но не грузите их на лист:

1. `CurrentBundlePath`
2. `ExportRootPath`
3. `fxCsv`
4. `fxCombineCsvFromBundles`
5. `Documents`
6. `Pages`
7. `Elements`
8. `ElementGroups`
9. `ElementSubtypes`
10. `Tables`
11. `TableCells`

### Загрузить на листы Excel

Создайте отдельные листы с такими именами:

1. `01_PageSummary` <- запрос `PageSummary`
2. `02_Elements` <- запрос `ElementsExpanded`
3. `03_Tables` <- запрос `TablesExpanded`
4. `04_Languages` <- запрос `LanguageSummary`

## Что вы получите на листах

`01_PageSummary`

- одна строка на страницу
- количества элементов по странице
- число таблиц, ячеек и языков
- быстро подходит для первичной оценки структуры PDF

`02_Elements`

- постраничный перечень элементов
- основные группы: текст, линии, рамки, изображения, таблицы
- геометрия, размеры, порядок отрисовки, логический слой, язык, признаки видимости

`03_Tables`

- найденные таблицы
- размеры, координаты, число строк и столбцов
- вложенные данные по связанным ячейкам

`04_Languages`

- сводка по языкам
- помогает быстро увидеть русский, английский и битые кодировки

## Сценарий для сравнения нескольких PDF

Если нужно анализировать сразу много выгруженных PDF, дополнительно загрузите на листы:

1. `90_All_PageSummary` <- запрос `AllBundles_PageSummary`
2. `91_All_Tables` <- запрос `AllBundles_Tables`

Это удобно для сравнения документов между собой через фильтры, сводные таблицы и Power Pivot.

## Практический порядок в Excel

1. `Данные -> Получить данные -> Из других источников -> Пустой запрос`
2. Откройте `Дополнительный редактор`
3. Вставьте код из соответствующего `.pq`-файла
4. Сохраните запрос с именем файла без расширения
5. Для служебных запросов выберите `Закрыть и загрузить в... -> Только подключение`
6. Для основных витрин выберите `Таблица` и загрузку на новый или существующий лист

## Рекомендуемые первые фильтры в Excel

На листе `02_Elements` обычно полезно сразу включать фильтры по:

- `page_number`
- `group_name`
- `subtype_name`
- `logical_layer_name`
- `detected_language`
- `has_broken_encoding`

На листе `03_Tables` обычно полезны:

- `page_number`
- `row_count`
- `column_count`
- `cell_count`
