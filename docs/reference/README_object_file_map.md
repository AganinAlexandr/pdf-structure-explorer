# Object File Map

Этот справочник нужен для связи результатов разбора PDF с внешними данными по объектам.

## Где хранить

Рабочий файл хранится вне репозитория:

- `E:\commons\pdf-structure-explorer\reference\object_file_map.csv`

В репозитории хранятся только:

- шаблон структуры
- описание полей

## Назначение

Справочник позволяет:

- привязать PDF-файл к объекту
- хранить тип раздела и подраздела
- учитывать случаи, когда один и тот же PDF найден в нескольких каталогах
- связывать экспорт приложения с внешним справочником через `file_name + file_crc32`

## Правило идентификации

Основной аналитический ключ:

- `file_name`
- `file_crc32`

Поля пути нужны как служебные и полезны на этапе обхода каталогов, но не должны считаться главным идентификатором файла.

## Рекомендуемая модель строк

Одна строка = одно найденное вхождение файла в каталоге.

Это позволяет:

- видеть все места, где найден файл
- не терять различия по каталогам
- позже при необходимости сворачивать одинаковые файлы по `file_name + file_crc32`

## Поля

- `object_code` — код или номер объекта
- `object_name` — человекочитаемое имя объекта
- `section_type` — вид раздела
- `subsection_type` — вид подраздела
- `file_name` — имя PDF-файла
- `file_crc32` — CRC32 файла в верхнем регистре, например `1ADE79D9`
- `source_root` — корневой каталог поиска
- `relative_path` — путь относительно корня поиска
- `full_path` — полный путь к файлу
- `file_size_bytes` — размер файла в байтах
- `last_modified` — дата и время последнего изменения
- `source_catalog_group` — имя набора каталогов или источника
- `is_preferred_source` — признак предпочтительного источника при дубликатах
- `notes` — комментарий

## Использование в Excel / Power Query

Базовая схема:

1. загрузить `object_file_map.csv`
2. загрузить `documents.csv` из выгрузки приложения
3. сделать merge по `file_name` и `file_crc32`
4. дальше расширять `PageSummary`, `ElementsExpanded`, `TablesExpanded` полями объекта

## Примечание

Если один и тот же PDF лежит в нескольких каталогах и файл идентичен, строки будут отличаться путями, но совпадут по:

- `file_name`
- `file_crc32`

Именно это и нужно для дальнейшей нормализации в Excel.
