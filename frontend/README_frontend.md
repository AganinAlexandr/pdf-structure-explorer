# Frontend pdf-structure-explorer (React + Vite + TS)

Базовый Viewer + Inspector по ТЗ (раздел 7): три колонки
Thumbnails | Page Viewer | Inspector.

## Возможности MVP

- загрузка PDF перетаскиванием в окно или кнопкой, авто-запуск разбора,
  прогресс-бар по /status, страницы появляются по мере разбора;
- миниатюры страниц с маркером числа таблиц;
- Page Viewer: превью страницы + SVG-оверлей всех элементов,
  масштаб 50–200%, листание;
- режимы подсветки (ТЗ 7.2): по типу элемента, по глубине (градиент
  от drawOrder), по языку (ru/en/unknown/broken), битые кодировки;
- режимы курсора: обычный, перекрестие, прицельный для мелких
  элементов (тонкая обводка), фокус (усиленная подсветка);
- Inspector: секция «Группы элементов» (счётчики, вкл/выкл, solo-фильтр,
  список элементов с переходом к объекту), карточка элемента под
  курсором/выбранного, карточка таблицы с ячейками и их текстом,
  секция «Слои» с бейджем «Логические слои», секция «Языки»;
- кнопка «Сбросить фильтры»; кнопка «Экспорт CSV» в шапке.

## Запуск

Режим разработки (с hot-reload, backend на 8000):

```bat
cd frontend
npm install
npm run dev      REM http://localhost:5173, запросы /api проксируются
```

Один порт (без node): собрать фронтенд и открыть через backend —
`frontend/dist` уже включён в архив, поэтому достаточно запустить
backend и открыть http://127.0.0.1:8000/

```bat
npm run build    REM пересборка dist после правок
```

## Замечания по производительности

CAD-страницы дают 6–8 тыс. SVG-прямоугольников в оверлее; элементы
подгружаются пакетами по 2000. При навигации по таким страницам удобно
отключать группу «Линии» в панели групп. Следующая оптимизация —
canvas-рендер оверлея вместо SVG.
